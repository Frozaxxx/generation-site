# Карточка компании

Карточка — единый источник фактов. Сайт берёт из неё имена, адреса, телефоны и характеристики продукта без изменений, а тексты может только адаптировать по подаче.

Машиночитаемая схема: [`company.schema.json`](company.schema.json). Тексты карточки хранятся на русском (`content_language: "ru"`), сайт выпускается на русском или немецком.

## Структура

| Раздел | Поля | Зачем |
|---|---|---|
| `brand` | `name`, `legal_form`, `legal_name`, `tagline`, `domain` | Бренд и юрлицо, домен для почты и метаданных сайта |
| `contacts` | `address` (улица, дом, индекс, город, район, земля, страна), `city_key`, `phone` (E.164), `phone_display`, `email`, `office_hours` | Контакты; `city_key` связывает адрес и телефон с каталогом |
| `history` | `founded_year`, `employees`, `founding_story`, `specialization`, `milestones[]` | История основания и специализация |
| `audience` | `segments[]`, `client_problem` | Целевая аудитория и проблема клиента |
| `product` | `name`, `summary`, `inputs[]`, `process[]`, `outputs[]`, `limitations[]`, `benefits[]`, `delivery` | Входные данные, процесс, результат и ограничения |
| `team[]` | `id`, `first_name`, `last_name`, `gender`, `age`, `role`, `position`, `department`, `bio`, `experience[]`, `education`, `photo` | Руководитель (`ceo`), руководители отделов (`department_head`), специалисты |
| `faq[]` | `question`, `answer` | Ровно 5 вопросов о продукте |

Рядом с карточкой компания хранит:

- `params` — итоговые параметры генерации и список полей, выбранных случайно;
- `generation` — модель, число запросов, токены, стоимость и «концепт», по которому строилась компания;
- `status` (`draft` / `approved`) и `revision`.

## Ревизии и утверждение

- Любая ручная правка увеличивает `revision` и возвращает карточку в черновик.
- Утвердить можно только карточку без ошибок проверки.
- Сайт собирается из снимка конкретной ревизии, поэтому правки карточки не меняют уже собранные версии сайта.
- При сохранении передаётся ревизия, с которой началось редактирование: если карточку уже изменили, сервер вернёт `409`.

## Проверки

Ошибки (`error`) блокируют утверждение, предупреждения (`warning`) — нет.

| Код | Что проверяется |
|---|---|
| `empty_field`, `placeholder` | Пустые поля и незаменённые переменные (`{company}`, `{{ city }}`, `[NAME]`, `TODO`) |
| `legal_name`, `legal_form` | Наименование юрлица содержит бренд и заканчивается правовой формой |
| `city_unknown`, `city_name`, `postal_code` | Город из каталога страны, индекс относится к городу |
| `phone_country`, `phone_city`, `phone_display` | Телефон с кодом страны и города, местная запись совпадает с E.164 |
| `phone_unreserved` (warning) | Номер вне блока Drama Numbers и может принадлежать реальному абоненту |
| `email_domain` | Почта на домене сайта |
| `founded_future`, `milestone_year` | Год основания и этапы истории не в будущем и не раньше основания |
| `person_age` (warning) | Сотрудник не был младше 18 лет при основании компании |
| `team_size`, `team_ceo`, `team_heads`, `team_department` | Не меньше 5 человек, один руководитель, минимум два руководителя отделов с указанным отделом |
| `team_duplicate_id`, `team_duplicate_name` | Нет повторов людей |
| `faq_size`, `faq_duplicate` | Ровно 5 разных вопросов |

## Каталог (Германия)

Города совпадают с блоками Drama Numbers: Berlin (030 23125 xxx), Frankfurt am Main (069 90009 xxx), Hamburg (040 66969 xxx), Köln (0221 4710 xxx), München (089 99998 xxx).

Масштабы:

| Масштаб | Сотрудников | Год основания | Людей на сайте |
|---|---|---|---|
| `small` | 8–30 | 2015–2022 | 5 |
| `medium` | 50–180 | 2008–2017 | 6–7 |
